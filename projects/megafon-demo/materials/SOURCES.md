# Предварительный каталог материалов — megafon-demo

**Статус: кандидаты источников; пакет T1 не завершён.** Оригинальный бриф организаторов в репозитории отсутствует, поэтому нельзя определить, какие именно материалы релевантны конкурсной задаче. Не подменять ими бриф.

## Открытые кандидаты

1. [Годовой отчет ПАО «МегаФон» за 2024 год](https://reportcollection.inion.ru/reports/download/?reportId=4813) — первичный корпоративный источник; утверждён 10.04.2025.
2. [ТМТ Рейтинг 2025 — российский рынок телекоммуникаций](https://tmt-consulting.ru/wp-content/uploads/2025/12/%D0%A2%D0%9C%D0%A2-%D1%82%D0%B5%D0%BB%D0%B5%D0%BA%D0%BE%D0%BC-2025.pdf) — отраслевые показатели и прогноз.
3. [НКР — аналитическое исследование телекоммуникаций](https://ratings.ru/files/research/corps/NCR_Telecom_Oct2025.pdf) — конкурентная структура и финансовые показатели.
4. [Росстат — Платное обслуживание населения в России, 2025](https://rosstat.gov.ru/storage/mediabank/Platnoe_obsluj_2025.pdf) — официальная статистика, включая телекоммуникационные услуги.
5. [Официальный каталог тарифов МегаФона](https://shop.megafon.ru/connect/tariffs) — динамическая HTML-страница; сохранять регион и дату снимка.
6. [Агрегированные отзывы о МегаФоне на Tarifgid](https://tarifgid.ru/kompaniya/megafon/otzyvy) — только качественные сигналы; отзывы подвержены самоотбору и не являются репрезентативной выборкой.

## Парсинг и блокеры

- Для PDF/DOCX/XLSX/CSV: после получения файла выполнить python tools/parse_doc.py <file> -o projects/megafon-demo/materials/parsed --url <source-url> --title "<title>". Проверить пару .md + .meta.json.
- Для HTML: использовать python tools/fetch_cache.py <url> --project megafon-demo, затем проверить .md и .meta.json.
- На 2026-11-22 ссылки просмотрены через web; загрузка бинарных PDF в рабочее окружение для выполнения парсера не удалась. Поэтому ни один материал не отмечен как parsed/cached.
- Перед S01 добавить оригинальный бриф с датой/версией и пересмотреть релевантность источников под его конкретные вопросы.
