# Архив предварительных источников — не использовать для текущего кейса

Этот список был составлен до получения исходного брифа и предполагал реальный проект МегаФона. Полученный документ описывает **вымышленного мобильного оператора**; все числа рынка и финансов в нём учебные.

Поэтому годовой отчёт МегаФона, обзоры телеком-рынка, Росстат, тарифы и отзывы не являются evidence для заданных числовых условий. Они не должны подменять учебные показатели.

Актуальный бриф: `projects/fictional-operator/brief.md`.

Внешние источники можно добавить только если отдельный вопрос исследования потребует проверки технологического или регуляторного контекста. Такой контекст следует маркировать отдельно от условий учебного кейса.
