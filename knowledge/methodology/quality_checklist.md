# Чек-лист качества (Quality Checklist)

> **Зачем это агенту:** Перед сдачей стратегии человеку (Гейт Шаг 6) агент должен сам себя проверить.

## Проверка стратегии
- [ ] Факты отделены от гипотез (в `claims.jsonl` есть статусы).
- [ ] Указаны источники для каждого факта.
- [ ] Рассмотрено ≥3 варианта (включая Status Quo и Kill).
- [ ] Для каждого варианта есть сильные возражения.
- [ ] Продуктовая и коммуникационная стратегии согласованы.
- [ ] Обещания в коммуникации подтверждаются продуктом (Proof).
- [ ] Есть план проверки с метриками, сроком и guardrails.
- [ ] Есть карточка решения с ответственным и условиями пересмотра.

## Проверка процесса
- [ ] Все шаги `workflow.md` пройдены.
- [ ] `state/journal.md` содержит записи о каждом шаге.
- [ ] `state/budget.json` не превышает лимит.
