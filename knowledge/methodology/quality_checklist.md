# Чек-лист качества

Применять перед S11 (human approval). S06 — только выбор варианта; стратегия ещё не утверждена.

- [ ] Факты отделены от гипотез/прогнозов; существенные claims имеют ID.
- [ ] Для каждого факта есть проверяемый источник или воспроизводимый расчёт.
- [ ] Не менее трёх разных вариантов, включая Status Quo и Kill.
- [ ] Для вариантов указаны ресурсы, риски, сильные возражения и условия успеха.
- [ ] Продуктовая и коммуникационная стратегии согласованы.
- [ ] Обещания коммуникации подтверждены возможностями продукта.
- [ ] План проверки содержит baseline, срок, guardrails и stop criteria.
- [ ] Critic findings обработаны с traceability.
- [ ] Journal фиксирует этапы, гейты и resume.
- [ ] Budget не превышает лимит; неизвестная цена не считается нулевой.
