# Устаревшая папка проекта

Этот каталог создан до получения исходного брифа и ошибочно предполагал реальный проект МегаФона.

**Не использовать для текущего задания.** Полученный бриф описывает вымышленного мобильного оператора и учебный рынок. Актуальный проект и проверенная структурированная версия брифа находятся в:

- `projects/fictional-operator/brief.md`
- `projects/fictional-operator/materials/brief.meta.json`
- `projects/fictional-operator/state/journal.md`

Все предварительные кандидаты реальных источников МегаФона не относятся к исходным числовым условиям учебного кейса. Не подменять ими данные брифа.
