# Skills catalog

The skills define how to perform each workflow stage. The authoritative stage order and human gates remain in `../workflow.md`.

| Skill | Workflow stage | Main output |
|---|---|---|
| [research.md](research.md) | S02–S03 | Research plan, source assessment, evidence and claims |
| [analysis.md](analysis.md) | S04 | Situation analysis, insights, gaps and implications |
| [options.md](options.md) | S05 | Status quo, strategic alternatives, Kill option and comparison |
| [strategy.md](strategy.md) | S07 | Product strategy and mandatory communication strategy |
| [critic.md](critic.md) | S08 / S10 | Adversarial review, findings, severity and verdict |
| [revision.md](revision.md) | S09 / S10 | Finding dispositions, changes and unresolved issues |
| [validation.md](validation.md) | S12–S13 | Requirements, evidence, coherence, readiness and handoff |

## Usage rules

1. Read the matching skill before its stage.
2. Follow `../workflow.md` for sequence, transitions, artifacts and gates.
3. Cite stable claim IDs from the project evidence ledger.
4. Never present a hypothesis, planned capability, estimate or unrun test as a verified fact.
5. Human gates require explicit human decisions; the skill cannot approve them.
